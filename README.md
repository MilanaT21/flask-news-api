# Flask News API

Веб-приложение для публикации и управления новостями, разработанное на Python и Flask. Проект был выполнен в рамках учебного задания.

## Возможности

### Веб-приложение

Пользователь может:

- зарегистрироваться;
- войти в аккаунт и выйти из него;
- просматривать все опубликованные новости;
- создавать собственные новости;
- редактировать свои новости;
- удалять свои новости;
- просматривать свои публикации в личном кабинете.

### REST API

Для пользователей и новостей реализованы CRUD-операции.

#### Пользователи

| Метод | Endpoint | Описание |
|---|---|---|
| GET | `/api/users` | Получить список пользователей |
| POST | `/api/users` | Создать пользователя |
| PUT | `/api/users/<id>` | Изменить данные пользователя |
| DELETE | `/api/users/<id>` | Удалить пользователя |

#### Новости

| Метод | Endpoint | Описание |
|---|---|---|
| GET | `/api/news` | Получить список новостей |
| POST | `/api/news` | Создать новость |
| PUT | `/api/news/<id>` | Изменить новость |
| DELETE | `/api/news/<id>` | Удалить новость |

Для обработки запросов используются соответствующие HTTP-статусы, включая `200 OK`, `201 Created`, `400 Bad Request`, `404 Not Found` и `409 Conflict`.
